1.Tanpa Generic

  • Pada program ini, Box merupakan class yang digunakan untuk menyimpan data.
  • Class Box menggunakan tipe data dynamic, sehingga dapat menampung berbagai jenis data.
  • Data yang disimpan awalnya berupa int, kemudian dapat diubah menjadi String.
  • Karena tidak ada pembatasan tipe data, program berpotensi mengalami kesalahan.
  • Kesalahan biasanya terjadi saat program dijalankan (runtime error).
  • Dengan demikian, penggunaan dynamic bersifat fleksibel namun kurang aman.

// Repository Generic
class Repository {
  List _items = [];

  void save(T item) {
    _items.add(item);
  }

  T getById(int id) {
    return _items[id];
  }

  List getAll() {
    return _items;
  }

// Fungsi swap
void swap(List list, int i, int j) {
  var temp = list[i];
  list[i] = list[j];
  list[j] = temp;
}

// Class Triple

  A first;
  B second;
  C third;

  Triple(this.first, this.second, this.third);
}

  repo.save(20);

  swap(list, 0, 2);

// Nama  : Yoza Ulpia Rafila
// NIM   : 251410004
// Kelas : SI.2A

// =======================
// 1. STACK
// =======================
class Stack {
  final List _items = [];

  void push(T value) {
    _items.add(value);
  }

  T? pop() {
    if (_items.isEmpty) return null;
    return _items.removeLast();
  }

  T? peek() {
    if (_items.isEmpty) return null;
    return _items.last;
  }
}

// =======================
// 2. MERGE LISTS
// =======================
List mergeLists(List a, List b) {
  return [...a, ...b];
}

// =======================
// 3. RESPONSE
// =======================
class Response {
  T? data;
  String? error;

  Response({this.data, this.error});
}

// =======================
// MAIN
// =======================
void main() {
  // Stack
  var stack = Stack();
  stack.push(10);
  stack.push(20);
  print('Peek: ${stack.peek()}');
  print('Pop: ${stack.pop()}');

  // Merge Lists
  var result = mergeLists([1, 2], [3, 4]);
  print('Merge: $result');

  // Response
  var res = Response(data: "Berhasil");
  print('Response: ${res.data}');
}

    return 'Product(name: $name, price: $price)';

}

// =======================
// MAIN
// =======================
void main() {
  // Repository untuk String
  var userRepo = Repository();
  userRepo.add("Alice");
  userRepo.add("Bob");

  print("User Repo: ${userRepo.getAll()}");

  // Repository untuk Product
  var productRepo = Repository();
  productRepo.add(Product("Laptop", 1000));
  productRepo.add(Product("Mouse", 200));

  print("Product Repo: ${productRepo.getAll()}");

  // Hapus data
  userRepo.remove("Alice");
  print("User Repo setelah hapus: ${userRepo.getAll()}");
}

15. Kesimpulan

Dari seluruh pembahasan yang telah dilakukan, dapat disimpulkan bahwa:

  • Konsep Generic pada Dart memungkinkan class dan function bekerja dengan berbagai tipe data.
  • Generic membuat program menjadi lebih fleksibel karena satu kode dapat digunakan untuk banyak tipe data.
  • Penerapan bounded generic seperti extends membantu membatasi tipe data agar lebih aman.
  • Generic class seperti Repository, Stack, Cache, dan Pair memudahkan pengelolaan data secara terstruktur.
  • Generic function seperti swap dan combine meningkatkan efisiensi tanpa perlu membuat banyak fungsi berbeda.
  • Penggunaan Generic dalam OOP membuat program lebih reusable, aman, dan mudah dikembangkan.
