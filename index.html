1.Tanpa Generic

  • Pada program ini, Box merupakan class yang digunakan untuk menyimpan data.
  • Class Box menggunakan tipe data dynamic, sehingga dapat menampung berbagai jenis data.
  • Data yang disimpan awalnya berupa int, kemudian dapat diubah menjadi String.
  • Karena tidak ada pembatasan tipe data, program berpotensi mengalami kesalahan.
  • Kesalahan biasanya terjadi saat program dijalankan (runtime error).
  • Dengan demikian, penggunaan dynamic bersifat fleksibel namun kurang aman.

Kode Program VS Code:


// Nama  : Yoza Ulpia Rafila
// NIM   : 251410004
// Kelas : SI.2A

// =====================
// TANPA GENERIC
// =====================
class Box {
  dynamic data;

  Box(this.data);
}

void main() {
  // Menyimpan data awal
  var box = Box(42);

  // Menampilkan data awal
  int value = box.data;
  print("Nilai awal: $value");

  // Mengubah data
  box.data = "Hello";

  // Menampilkan data setelah diubah
  print("Data setelah diubah: ${box.data}");
}

2.Dengan Generic

  • Pada program ini, Box<T> digunakan sebagai class generic yang dapat menyimpan berbagai tipe data sesuai dengan tipe yang diberikan.
  • Tipe <T> memungkinkan class Box menjadi fleksibel, sehingga dapat digunakan untuk menyimpan data bertipe int, String, atau tipe lainnya.
  • Pada fungsi main(), dibuat dua objek yaitu Box<int> dan Box<String> untuk menyimpan data dengan tipe yang berbeda.
  • Program kemudian menampilkan isi dari masing-masing objek menggunakan print(), sehingga terlihat bahwa setiap Box menyimpan data sesuai dengan tipe yang telah ditentukan.
  • Dengan penggunaan generic, program menjadi lebih aman karena tipe data tidak dapat diubah sembarangan, sehingga menghindari kesalahan tipe data saat program dijalankan.

3.Sintaks Generic Class dan Function

  • Pada program ini, MyClass<T> digunakan sebagai class generic yang dapat menyimpan berbagai tipe data sesuai dengan tipe yang diberikan.
  • Tipe <T> membuat class MyClass menjadi fleksibel, sehingga dapat digunakan untuk menyimpan data bertipe int, String, atau tipe lainnya.
  • Method getData() digunakan untuk mengambil nilai yang tersimpan di dalam class sesuai dengan tipe data yang telah ditentukan.
  • Selain itu, terdapat generic function yaitu myFunc<T> yang dapat menerima dan mengembalikan nilai dengan tipe yang sama, sehingga fungsi ini juga bersifat fleksibel terhadap berbagai tipe data.
  • Pada fungsi main(), dibuat objek MyClass<int> dan MyClass<String>, serta pemanggilan fungsi myFunc dengan tipe int dan String.
  • Program kemudian menampilkan hasil menggunakan print(), sehingga terlihat bahwa setiap data diproses sesuai dengan tipe yang telah ditentukan.
  • Dengan penggunaan generic, program menjadi lebih aman dan terstruktur karena tipe data sudah ditentukan sejak awal, sehingga mengurangi kesalahan saat program dijalankan.

Kode Program VS Code:


// Nama  : Yoza Ulpia Rafila
// NIM   : 251410004
// Kelas : SI.2A

class MyClass {
  T data;

  MyClass(this.data);

  T getData() {
    return data;
  }
}

// Generic function
T myFunc(T value) {
  return value;
}

void main() {
  var myInt = MyClass(10);
  var myString = MyClass("test");

  print(myInt.getData());
  print(myString.getData());

  var intValue = myFunc(100);
  var stringValue = myFunc("hello");

  print(intValue);
  print(stringValue);
}

4.kelas Box

  • Pada program ini, Box<T> digunakan sebagai generic class yang berfungsi untuk menyimpan data dengan berbagai tipe sesuai dengan tipe yang diberikan.
  • Tipe <T> membuat class Box menjadi fleksibel, sehingga dapat digunakan untuk menyimpan data bertipe int, String, double, maupun tipe lainnya.
  • Variabel _value bersifat private dan digunakan untuk menyimpan nilai, sedangkan getter value digunakan untuk mengambil nilai tersebut dari luar class.
  • Method setValue() digunakan untuk mengubah nilai yang ada di dalam objek Box sesuai dengan tipe data yang telah ditentukan.
  • Pada fungsi main(), dibuat beberapa objek yaitu Box<int>, Box<String>, dan Box<double> untuk menunjukkan bahwa class dapat digunakan dengan berbagai tipe data.
  • Program menampilkan nilai awal dan nilai setelah diubah menggunakan print(), sehingga terlihat bahwa data dapat diakses dan dimodifikasi dengan aman.
  • Dengan penggunaan generic, program menjadi lebih aman dan terstruktur karena tipe data sudah ditentukan sejak awal, sehingga menghindari kesalahan tipe data saat program dijalankan.

Kode Program VS Code:


// Nama  : Yoza Ulpia Rafila
// NIM   : 251410004
// Kelas : SI.2A

class Box {
  T? _value;

  Box(this._value);

  T? get value => _value;

  void setValue(T value) {
    _value = value;
  }
}

void main() {
  var intBox = Box(10);
  print("Int Box: ${intBox.value}");

  intBox.setValue(20);
  print("Set Int: ${intBox.value}");

  var stringBox = Box("Hello");
  print("String Box: ${stringBox.value}");

  stringBox.setValue("World");
  print("Set String: ${stringBox.value}");

  var doubleBox = Box(3.14);
  print("Double Box: ${doubleBox.value}");
}

5.Multiple Type Parameters

  • Pada program ini, Pair<K, V> merupakan generic class dengan dua parameter tipe yang digunakan untuk menyimpan sepasang data yang saling berhubungan, yaitu key dan value.
  • Parameter <K> digunakan sebagai tipe untuk key, sedangkan <V> digunakan sebagai tipe untuk value, sehingga class ini menjadi fleksibel untuk berbagai kombinasi tipe data.
  • Class Pair memiliki constructor untuk menginisialisasi nilai key dan value saat objek dibuat.
  • Method printPair() digunakan untuk menampilkan pasangan data key dan value ke layar menggunakan print().
  • Pada fungsi main(), dibuat beberapa objek yaitu Pair<String, int>, Pair<String, String>, dan Pair<int, double> untuk menunjukkan bahwa class dapat digunakan dengan berbagai tipe data.
  • Program kemudian menampilkan isi dari masing-masing objek, sehingga terlihat bahwa setiap pasangan data diproses sesuai dengan tipe yang telah ditentukan.
  • Dengan penggunaan generic, program menjadi lebih aman, fleksibel, dan mengurangi kemungkinan kesalahan tipe data saat dijalankan.

Kode Program VS Code:


// Nama  : Yoza Ulpia Rafila
// NIM   : 251410004
// Kelas : SI.2A

class Pair {
  K key;
  V value;

  Pair(this.key, this.value);

  void printPair() {
    print("Key: $key, Value: $value");
  }
}

void main() {
  var pair1 = Pair("age", 30);
  pair1.printPair();

  var pair2 = Pair("name", "Alice");
  pair2.printPair();

  var pair3 = Pair(1, 2.71);
  pair3.printPair();
}

6.Penerapan Generic Menggabungkan Dua Tipe Data

  • Pada program ini, combine<T, U> merupakan generic function yang digunakan untuk menggabungkan dua nilai dengan tipe data yang berbeda.
  • Parameter <T> dan <U> memungkinkan fungsi ini menerima dua jenis tipe data yang berbeda, sehingga lebih fleksibel digunakan.
  • Fungsi combine() akan mengembalikan hasil berupa String yang berisi gabungan dari value1 dan value2.
  • Pada fungsi main(), dilakukan pemanggilan fungsi combine<String, int> untuk menggabungkan teks dan angka, serta combine<int, double> untuk menggabungkan dua angka dengan tipe berbeda.
  • Hasil dari fungsi kemudian ditampilkan menggunakan print(), sehingga terlihat bahwa fungsi dapat bekerja dengan berbagai kombinasi tipe data.
  • Dengan penggunaan generic function, program menjadi lebih fleksibel karena satu fungsi dapat digunakan untuk berbagai jenis tipe data tanpa harus membuat fungsi yang berbeda-beda.

Kode Program VS Code:


// Nama  : Yoza Ulpia Rafila
// NIM   : 251410004
// Kelas : SI.2A

String combine(T value1, U value2) {
  return '$value1, $value2';
}

void main() {
  var result1 = combine('Number is', 10);
  print(result1);

  var result2 = combine(10, 20.5);
  print(result2);
}

7.Generic Dengan Extends

  • Pada program ini, NumberBox<T> merupakan generic class yang digunakan untuk menyimpan data dengan tipe tertentu, namun memiliki batasan hanya untuk tipe numerik.
  • Penggunaan <T extends num> berarti tipe T hanya boleh berupa tipe data yang termasuk dalam kategori angka, seperti int dan double.
  • Hal ini membuat class NumberBox tidak dapat digunakan untuk tipe selain numerik, misalnya String, sehingga meningkatkan keamanan tipe data (type safety).
  • Constructor NumberBox(this.value) digunakan untuk menginisialisasi nilai awal saat objek dibuat.
  • Method getValue() digunakan untuk mengambil dan mengembalikan nilai yang tersimpan di dalam objek.
  • Pada fungsi main(), dibuat objek NumberBox<int> dan NumberBox<double> yang menunjukkan bahwa class hanya dapat digunakan untuk tipe numerik.
  • Baris NumberBox<String> tidak dapat digunakan karena akan menghasilkan error, sebab String bukan termasuk tipe numerik.
  • Dengan penggunaan bounded generic, program menjadi lebih aman karena tipe data dibatasi sesuai kebutuhan, sehingga mengurangi kesalahan saat program dijalankan.

Kode Program VS Code:


// Nama  : Yoza Ulpia Rafila
// NIM   : 251410004
// Kelas : SI.2A

class NumberBox {
  T value;

  NumberBox(this.value);

  T getValue() {
    return value;
  }
}

void main() {
  var intBox = NumberBox(10);
  print("Int: ${intBox.getValue()}");

  var doubleBox = NumberBox(3.14);
  print("Double: ${doubleBox.getValue()}");

  // var stringBox = NumberBox("test"); // ❌ Error
}

8.Type Inference (Inferensi Tipe)

  • Pada program ini, myFunc<T> merupakan generic function yang digunakan untuk menerima dan mengembalikan nilai dengan tipe data yang sama.
  • Tipe <T> membuat fungsi ini bersifat fleksibel karena dapat digunakan untuk berbagai jenis data seperti int, String, dan tipe data lainnya.
  • Fungsi myFunc() hanya mengembalikan nilai yang dikirimkan tanpa mengubah tipe datanya, sehingga tetap sesuai dengan input yang diberikan.
  • Pada fungsi main(), pemanggilan myFunc(10) secara otomatis akan bertipe int, dan myFunc("test") akan bertipe String karena Dart mendeteksi tipe secara otomatis (type inference).
  • Method runtimeType digunakan untuk menampilkan tipe data asli dari variabel saat program dijalankan.
  • Dengan penggunaan generic function, program menjadi lebih sederhana, fleksibel, dan tetap aman karena tipe data tetap konsisten antara input dan output.

Kode Program VS Code:


// Nama  : Yoza Ulpia Rafila
// NIM   : 251410004
// Kelas : SI.2A

T myFunc(T value) {
  return value;
}

void main() {
  var intValue = myFunc(10); // otomatis int
  print(intValue.runtimeType);

  var stringValue = myFunc("test"); // otomatis String
  print(stringValue.runtimeType);
}

9.Pembatasan Tipe Pada Interface dan Class

  • Pada program ini, printIterable<T extends Iterable<dynamic>> merupakan generic function yang digunakan untuk mencetak semua elemen dari sebuah data yang bersifat iterable.
  • Batasan <T extends Iterable<dynamic>> berarti fungsi ini hanya dapat menerima tipe data yang bisa diiterasi seperti List dan Set.
  • Fungsi printIterable() akan melakukan perulangan menggunakan for-in loop untuk menampilkan setiap elemen yang ada di dalam koleksi data.
  • Pada fungsi main(), digunakan List<int> dan Set<String> sebagai contoh data yang valid karena keduanya termasuk tipe Iterable.
  • Baris printIterable<int>(10) akan menghasilkan error karena tipe int bukan termasuk Iterable, sehingga tidak dapat digunakan dalam fungsi ini.
  • Dengan penggunaan bounded generic pada Iterable, program menjadi lebih aman karena hanya menerima struktur data yang dapat diiterasi, sehingga menghindari kesalahan saat runtime.

Kode Program VS Code:

void printIterable>(T iterable) {
  for (var item in iterable) {

  }

  printIterable>({'apple', 'banana'});

10.Pembatasan Tipe Dengan Class Abstarct

  • Pada program ini, Animal merupakan abstract class yang berfungsi sebagai dasar (blueprint) untuk kelas turunan lainnya dan memiliki method abstrak makeSound().
  • Class Dog dan Cat mengimplementasikan (implements) class Animal, sehingga wajib mengoverride method makeSound() sesuai dengan perilaku masing-masing hewan.
  • Class AnimalCage<T extends Animal> merupakan generic class yang hanya dapat menerima tipe data yang merupakan turunan dari Animal.
  • Batasan <T extends Animal> memastikan bahwa hanya objek yang memiliki perilaku makeSound() yang dapat digunakan dalam class ini.
  • Method sound() digunakan untuk memanggil method makeSound() dari objek hewan yang disimpan di dalam kandang.
  • Pada fungsi main(), dibuat objek AnimalCage<Dog> dan AnimalCage<Cat> untuk menunjukkan bahwa class ini dapat digunakan dengan berbagai jenis hewan.
  • Baris AnimalCage<String> akan menghasilkan error karena String bukan turunan dari Animal.
  • Dengan penggunaan bounded generic dan konsep inheritance, program menjadi lebih aman, terstruktur, dan mendukung prinsip polymorphism dalam OOP.

Kode Program VS Code:


// Nama  : Yoza Ulpia Rafila
// NIM   : 251410004
// Kelas : SI.2A

abstract class Animal {
  void makeSound();
}

class Dog implements Animal {
  @override
  void makeSound() {
    print("Woof!");
  }
}

class Cat implements Animal {
  @override
  void makeSound() {
    print("Meow!");
  }
}

class AnimalCage {
  T animal;

  AnimalCage(this.animal);

  void sound() {
    animal.makeSound();
  }
}

void main() {
  var dogCage = AnimalCage(Dog());
  dogCage.sound();

  var catCage = AnimalCage(Cat());
  catCage.sound();

  // var wrong = AnimalCage("test"); // ❌ Error
}
